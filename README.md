# Workout App Starter

Use this starter with `part1.md` and `part2.md`. The workout model, routes, forms, and page layout are provided. Controllers and frontend data operations are unfinished.

Install backend and frontend dependencies separately with `npm install`. Copy `backend/.env.example` to `backend/.env`, configure MongoDB, and run `npm run dev` in each folder. The default backend port is 4000; Vite proxies `/api` to that port.

Install Vitest and Supertest in Part 1 Iteration 4. Install bcryptjs and jsonwebtoken in Part 2 Iteration 5.

Keep your `.env` file and generated `node_modules` folders out of version control. Use `.env.example` to document the environment variables your application needs.
